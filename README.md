## Why Hashformers?

🔒 **Privacy-First** — Run entirely offline on your infrastructure. No data leaves your machine. No OpenAI API calls. Perfect for sensitive codebases and enterprise environments.

🎯 **Universal Segmentation** — Works on any concatenated text:

| Input | Output |
|-------|--------|
| `AbstractSingletonProxyFactoryBean` | `Abstract Singleton Proxy Factory Bean` |
| `paypal-secure-login` | `paypal secure login` |
| `getUserAccountById` | `get User Account By Id` |
| `#weneedanationalpark` | `we need a national park` |

🏆 **State-of-the-Art** — Published at [LREC 2022](https://aclanthology.org/2022.lrec-1.782.pdf), achieving best-in-class performance on standard benchmarks.

🌍 **Language-Agnostic** — Use any language model from the [Hugging Face Model Hub](https://huggingface.co/models) to segment text in any language.

### Applications

Word segmentation powers a wide range of real-world applications:

- **Social Media Analysis** — Segment hashtags to significantly improve the performance of sentiment analysis and event detection pipelines.
- **Source Code Processing** — Split identifiers (e.g., `class_name` or `variableName`) to assist with code summarization and clone detection.
- **Text Restoration** — Repair missing or corrupted spacing in text extracted from PDFs or generated by Optical Character Recognition (OCR) systems.
- **Machine Translation** — Perform compound splitting for languages like German or Dutch to enable accurate word alignment and translation.
- **Search & SEO** — Normalize user queries (e.g., "cheapflights") and segment URLs to improve keyword indexing and content classification.
- **Cybersecurity** — Estimate password entropy by detecting dictionary words and analyze domain names to flag potential phishing attacks.
- **Speech Processing** — Convert continuous phoneme streams into discrete words for ASR and determine correct prosody for Text-to-Speech (TTS) systems.
- **Historical Research** — Process and segment historical manuscripts that utilize *scriptura continua* (writing without spaces).
- **CJK Language Processing** — Segment Chinese, Japanese, and Thai text where words are written without spaces, enabling tokenization for NLP tasks.

## Basic Usage

```python
from hashformers import TransformerWordSegmenter as WordSegmenter

ws = WordSegmenter(
    segmenter_model_name_or_path="gpt2",
    segmenter_model_type="incremental",
    reranker_model_name_or_path="google/flan-t5-base",
    reranker_model_type="seq2seq"
)

segmentations = ws.segment([
    "AbstractSingletonProxyFactoryBean",
    "paypal-secure-login",
    "#icecold"
])

print(segmentations)
# ['Abstract Singleton Proxy Factory Bean',
#  'paypal secure login',
#  'ice cold']
```

It is also possible to use hashformers without a reranker by setting the `reranker_model_name_or_path` and the `reranker_model_type` to `None`. 

## Use Cases

### Source Code Identifier Segmentation

Perfect for code analysis, documentation generation, and IDE tooling:

```python
# CamelCase / PascalCase
ws.segment(["getUserById", "AbstractFactoryPattern", "IOException"])
# ['get User By Id', 'Abstract Factory Pattern', 'IO Exception']
```

### URL Slug Parsing

Extract readable text from URL slugs and paths:

```python
ws.segment(["paypal-secure-login", "forgot-password-reset", "user-account-settings"])
# ['paypal secure login', 'forgot password reset', 'user account settings']
```

### Hashtag Segmentation

The original use case — segment social media hashtags:

```python
ws.segment(["#weneedanationalpark", "#MakeAmericaGreatAgain", "#ThrowbackThursday"])
# ['we need a national park', 'Make America Great Again', 'Throwback Thursday']
```

## What Models Can I Use?

Visit the [HuggingFace Model Hub](https://huggingface.co/models) and choose your models for the `WordSegmenter` class.

Hashformers supports the following model types as the `segmenter_model_type` or `reranker_model_type`:

### `incremental`

Auto-regressive models like GPT-2 and XLNet, or any model that can be loaded with `AutoModelForCausalLM`. This includes large language models (LLMs) such as Alpaca-LoRA ( `chainyo/alpaca-lora-7b` ) and GPT-J ( `EleutherAI/gpt-j-6b` ).

```python
ws = WordSegmenter(
    segmenter_model_name_or_path="EleutherAI/gpt-j-6b",
    segmenter_model_type="incremental",
    reranker_model_name_or_path=None,
    reranker_model_type=None
)
```

### `masked`

Masked language models like BERT, or any model that can be loaded with `AutoModelForMaskedLM`.

### `seq2seq`

Seq2Seq models like FLAN-T5 ( `google/flan-t5-base` ), or any model that can be loaded with `AutoModelForSeq2SeqLM`.

Best results are usually achieved by using an `incremental` model as the `segmenter_model_name_or_path` and a `masked` or `seq2seq` model as the `reranker_model_name_or_path`. 

A segmenter is always required, however a reranker is optional. 

## Integrations

Hashformers integrates with popular data processing and NLP frameworks for production deployments:

| Framework | Description |
|-----------|-------------|
| **PySpark** | Distributed processing on Databricks, AWS EMR, and Spark clusters |
| **Haystack** | Document pipelines for search, RAG, and question answering |
| **LangChain** | LLM chains and document transformers |
| **spaCy** | NLP pipeline preprocessing |

```python
# PySpark example
from hashformers.integrations.spark import SparkHashformer

segmenter = SparkHashformer(inputCol="hashtag", outputCol="segmented")
result = segmenter.transform(spark_df)

# Haystack example
from hashformers.integrations.haystack import HashformersSegmenter

segmenter = HashformersSegmenter(segment_hashtags=True)
result = segmenter.run(documents=docs)
```
